Override Modal Test

This is a simple test to verify the override modal can be opened in the browser.

  1. Open frontend/index.html in a web browser
  2. Fill out the patient intake form with test data
  3. Click "Get AI Triage Recommendation" button
  4. Wait for prediction results to appear
  5. Click "Override ESI Level" button
  6. Verify the override modal appears with:
    • ML predicted ESI and confidence
    • Radio buttons for ESI 1-5 selection
    • Side-by-side comparison showing ML vs Clinician decision
    • Reason category dropdown
    • Free-text justification field (minimum 20 characters)
    • Override direction display (escalation/de-escalation)
    • Cancel and Submit buttons
  7. Select a different ESI level and verify:
    • Clinician decision box updates
    • Override direction updates (escalation if lower ESI, de-escalation if higher)
    • Color coding changes based on direction
  8. Fill in reason category and justification text (at least 20 characters)
  9. Click "Submit Override" button
  10. If escalating (lower ESI), verify escalation warning appears
  11. Confirm and verify success message with override details
  12. Check backend logs or data/overrides.json to verify override was saved

Test Scenarios

Scenario 1: Agreement (no change)

  • ML predicts ESI 2
  • Clinician selects ESI 2
  • Should show "✅ Agreement" in green

Scenario 2: Escalation

  • ML predicts ESI 3
  • Clinician selects ESI 2
  • Should show "⬆️ Escalation (higher urgency)" in red
  • Should display escalation warning before submitting

Scenario 3: De-escalation

  • ML predicts ESI 2
  • Clinician selects ESI 3
  • Should show "⬇️ De-escalation (lower urgency)" in yellow

Requirements Validated

Requirements: 4.1-4.10

  • ✅ 4.1: Override dialog triggered by "Override Recommendation" button
  • ✅ 4.2: ESI level selector with radio buttons 1-5
  • ✅ 4.3: Reason category dropdown
  • ✅ 4.4: Free-text justification field (minimum 20 characters)
  • ✅ 4.5: Side-by-side comparison (ML vs Clinician)
  • ✅ 4.6: Override direction display with color coding
  • ✅ 4.7: POST to /api/v1/override endpoint on submit
  • ✅ 4.8: Success confirmation dialog
  • ✅ 4.9: Clinician ESI accepted as final decision
  • ✅ 4.10: Escalation warning for higher urgency overrides

Manual Testing Instructions

  1. Ensure backend server is running: python app.py
  2. Open frontend/index.html in browser
  3. Test with a demo patient or enter custom data
  4. Complete all 3 test scenarios above
  5. Verify override is logged in data/overrides.json
